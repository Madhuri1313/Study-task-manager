# 📘 Study Task Manager

A modern and interactive **web-based task manager** designed to help students organize and track their daily study tasks efficiently.

Built using **HTML, CSS, and JavaScript**, this project focuses on clean UI design, smooth user experience, and practical task management features.

---

## 🚀 Features

* ➕ Add new tasks with due dates
* 🗑️ Delete tasks easily
* ✏️ Edit existing tasks
* ✅ Mark tasks as completed
* ⏳ Track pending and completed tasks
* 🔍 Search tasks instantly
* 🎯 Filter tasks (All / Pending / Completed)
* 📊 Dashboard showing task statistics
* 💾 Persistent storage using localStorage

---

## 🖥️ Tech Stack

* **HTML** – Structure
* **CSS** – Styling & UI Design
* **JavaScript** – Functionality & Logic
* **localStorage** – Data persistence

---





## 🎯 Key Highlights

* Designed a **clean and modern UI** with a consistent color theme
* Implemented **dynamic DOM manipulation** for real-time updates
* Used **JavaScript event handling** for user interactions
* Built a **responsive layout** for better usability
* Applied **localStorage** to retain tasks after page reload
